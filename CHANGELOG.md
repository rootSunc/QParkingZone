# Changelog

All notable changes to QParking Zones will be documented in this file.

This project follows the spirit of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and uses semantic versioning once public releases are tagged.

## 1.1.0 - 2026-05-31

### Added

- Open source project governance files and contribution workflow documentation.
- OpenAPI contract and generated frontend API response types.
- Zone facets endpoint for type, status, and amenity filter metadata.
- Request IDs, access logs, and database readiness details in the API.
- Docker smoke test for the production-style stack.

### Changed

- Split frontend lint scripts into check and fix modes.
- Updated Docker runtime to serve the API through Apache.
- Refined the README architecture diagram and project description.

### Fixed

- Resolved current frontend dependency audit advisories.
